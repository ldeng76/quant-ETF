# 0001 - 做T回测使用自研轻量引擎，不引入回测框架

做T回测需要"底仓不动、T单两腿等量对倒、14:55 强制当日闭环、份制仓位、T+1 可卖量约束"这些非常规语义，与 backtrader/vectorbt 等通用框架的订单-仓位抽象冲突大于收益；且项目（quant-ETF）整体是自研轻量、零重框架依赖的风格，分钟数据链路（minute_bars → resample_bars）已经齐备。决定自研逐bar事件循环 + 自建订单账本（核心循环预计 300–500 行），信号确认→次bar开盘成交的防未来函数编排由自己完全掌控。

## Considered Options

- backtrader / vectorbt：现成撮合与绩效报表，但等量对倒、当日强制闭环需绕开框架仓位模型，长期是负资产。
- 自研轻量引擎（选定）。

## Consequences

- 绩效报表、净值曲线等通用件需自己写（`t_trade/metrics.py`），换取状态语义的完全表达力。
- 未来若要做非做T类策略的回测，本引擎不通用；届时按需评估，不提前抽象。
