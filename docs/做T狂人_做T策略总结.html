「做T狂人」做T策略拆解

今日头条博主 · 近1500篇微头条 + 60余篇长文 · 本报告基于其公开发布内容整理
核心：96均线 + RSI(6) 132交易法 共振理论 T循环 波段操作法 价格预测法 底仓5成 + 机动5成

一句话总纲

不做预测，只做差价；不赌方向，只赚振幅。 用一根 96均线 定趋势方向，用一个 参数为6的RSI 定超买超卖买卖点，用 大盘/板块/个股三级共振 定出手时机，用 "10份底仓 + 10份资金" 的仓位纪律兜底。向上做正T赚差价，向下做反T赚差价，长线底仓雷打不动等翻番行情——目标是把底仓成本逐步做到趋近于零甚至负数。

他反复强调全书只讲三个字：差价、差价、差价。所有指标、级别、共振、仓位，最终都服务于"降低底仓成本"这一个目标。因此他自称"涨也欢喜、跌也欢喜"——涨了正T赚差价，跌了反T照样赚差价。

一、理论体系：5大交易体系

1. 「132」交易法 —— 整个体系的骨架

1
1个核心
超短线做T投机 + 超长线价值投资相结合。大仓位（底仓）不动，小仓位（浮动仓）反复收割。
3
3个完全分类
以96均线为界，走势有且仅有三种：上升、下降、横向盘整。分得清"上下横"，就会做T。
2
2个高胜率模式
大盘+板块+个股"同频共振"时的正T/反T机会。平时1份1份做，此时可"重拳出击"。

2. 三个完全分类 → 三种操作侧重

96均线状态走势性质主攻方向关键提醒
均线总体上行 上升趋势 以正T为主（先买后卖） 若K线远远高于均线，物极必反，可视情况反T。
均线总体横走 盘整/箱体 正T、反T都可做 K线远离均线时做T效果更好——箱体上下沿来回套利。
均线总体下行 下降趋势 以反T为主（先卖后买） 若K线远远低于均线，物极必反，可视情况正T。
为什么他"更喜欢做反T"？ A股是结构化行情，跌多涨少、急涨缓跌——在这种市场里 反T的机会天然更多、胜率更高。多数散户只爱做正T，是认知盲区。

3. 共振理论 —— 把"赌运气"变成"算概率"

  • 横向共振：大盘、板块、个股三者96均线方向一致。三者都看涨 → 正T成功率高；都看跌 → 反T成功率高；都盘整 → 正反都高；走势不一致 → 忍住不做。
  • 纵向共振：同一标的多个时间级别方向一致（如15分钟与5分钟96均线同时上行）。
  • 核心口诀：顺势而为——但"顺势绝不是无脑跟风"，背后是"随大势、逆小势"：顺大级别趋势，逆小级别回调。

4. 波段操作法 —— 做T的"无缝升级版"

与做T同源，只是把级别放大：做T看5分钟/1分钟，做波段看60分钟及以上。逻辑完全一样——96均线定方向、RSI定买卖点，只是差价更大、频次更低、留给思考的时间更多。

资金量小的人的建议 做T受资金限制时，不如放弃5分钟的小红绿柱，改去60分钟级别做波段。别人辛辛苦苦做几十次T，你一次波段的差价可能比他还多。"先易后难，慢就是快"。

5. T循环理论 & 价格预测法

  • T循环：植根于波浪理论、缠论（三类买卖点、区间套、多级别背驰）、格兰威尔八大买卖法则。核心是"顺大逆小、大的不动小的收割"——日内情绪相对有序，所以日内差价可稳定获得；做错了不急，小本子记着，过几天循环回来自然就对了。
  • 价格预测法：目标"买在下影线、卖在上影线"，让差价最大化。核心是提前计算、提前挂单委托、尽量保证成交。主要用于"上升趋势中的急跌/回调"与"下降趋势中的急涨/反弹"两种场景。
影线战法的底层逻辑（他改进自一位姓殷的股民） 前人说法："线上阴线买，买错也要买；线下阳线抛，抛错也要抛。"
他改为：「线上下影线买，买错也要买；线下上影线抛，抛错也要抛。」
把"阴阳"换成"影线"——因为 下影线是"跌不动"的证明，上影线是"涨不动"的证明。趋势会保护你，所以买错也要买、抛错也要抛。

三、实操：正T与反T的完整打法

▲ 正T（先买后卖）· 上升趋势主用

  • 适用：低开/盘中急跌、回踩支撑企稳、上升趋势中的回调。
  • 操作：支撑位用机动资金低吸 → 冲高滞涨/背离时卖出同等数量底仓。
  • 结果：底仓股数不变，现金增加，成本下降。
  • 优点：不会卖飞底仓，心态稳，适合新手先练。
  • 缺点：买后继续跌会临时加重仓位。

▼ 反T（先卖后买）· 下降趋势主用

  • 适用：高开冲高、放量滞涨、反弹遇压回落。
  • 操作：冲高乏力时先卖出一部分底仓 → 回落缩量企稳后同等数量买回。
  • 结果：筹码总数不变，规避回调，成本下降。
  • 优点：A股跌多涨少，反T机会更多。
  • 缺点：卖后一路拉升会"T飞"，难度更高。

高胜率正T模式（重拳出击条件，缺一不可）

1
趋势前提
15分钟周期96均线上行 + 5分钟周期96均线上行。
2
当日形态
高开或平开高走，先小幅上涨1~2个点，之后回调。
3
回调位置
回调不有效跌破上一交易日的成交密集区（"收拳头"）；出现止跌信号——5分钟底分型 + 成交量缩小。把握困难时去1分钟看6均线/24均线，或看底背驰形态（下跌—小涨—缓跌止跌）。
4
环境验证
大盘、板块环境平稳，无大跌风险。三者共振看涨时胜率最高。

高胜率反T模式（对称条件）

  • 15分钟96均线下行 + 5分钟96均线下行。
  • 低开或平开低走，先小幅下跌1~2个点，之后无量反弹。
  • 反弹不有效突破上一交易日成交密集区，出现5分钟顶分型。
  • 大盘、板块环境不佳、无看涨预期。
  • 与正T"慢慢观察"不同，反T需要眼疾手快——多数情况下1分钟6均线死叉24均线就是见顶信号，必须立即出手。
"走势漏洞"的本质 他称之为"打拳"：先把拳头收回来，再打出去才有力量。要抓的就是"收拳头 → 再打出去"中间的这段机会。这不是百分百的规律，只是概率上占优的位置。把这套模式做熟后，就可结合仓位资金管理"重拳出击"，既不会被套也不会T飞。

四、仓位管理：整套体系的"生命线"

他反复强调：盈利的核心是仓位管理，而非技术分析。 "技术分析无法雪中送炭，只能锦上添花。" —— 新手别沉迷技术误区，先把仓位加减做好。

资金拆分：10份底仓 + 10份机动

50%
底仓（10份）
"雷打不动"，只做正的降低成本，不因看好而增加、不因恐慌而减少。是你在个股里的"根据地"，是心态的锚。
50%
机动资金（10份）
专门做T、做波段。把握不大时1份1份做，把握大时多份出击。这是"132"的安全基础。
≈0
目标：成本趋于零
通过无数次差价把底仓成本逐步压低，最终目标"无限接近于0甚至负数"。

仓位铁律

  • 轻仓是前提："轻仓才能霸道"。轻仓试错 → 逐步加重 → 胜率必然越来越高。
  • 分批有序：绝不搞"一锤子买卖"，1份1份做。
  • 买卖数量对等：买多少后面就卖多少，防止仓位被动变化，把做T做成加仓。
  • 当日闭环：当天买的当天T出去，当天卖的尽量当天接回，不留隔夜T单。
  • 做错要认：做T失败不硬扛、不逆势加仓摊薄，防止小错变大亏。
  • 最简单的新手规则：仓位重 → 逢涨/逢反弹做反T；仓位轻 → 逢跌/逢回调做正T。八个字："涨舍得卖，跌敢于买"。
  • 100股买卖法：新手可用每次100股的最小单位练手，不必纠结手续费。

选股标准（做T的前提，选错票再好的手法也没用）

维度标准
基本面国资背景（防退市）、现金流好、净资产高、业绩优、高分红；"没有不好的股票，只有不好的操作"，但前提是不退市不停牌。
价格位置月线级别处于底部区域（近3年未涨超1倍），价格10元左右为佳。
活跃度1000天平均振幅 > 3%（"不怕股票不大涨，就怕股票没振幅"）；流动性充足，避免做T做不动。
分散配置常年持有 8只 不同行业的个股，东方不亮西方亮。强股做正T（锦上添花），弱股做反T（落井下石），不强不弱则不操作、耐心等。
建仓方式 价值股在月/周线级别底背驰 + 放量上涨后，回调时开始建仓。以5分钟96均线为参照，1份1次做正T建仓，"每笔底仓不涨不卖"，直到完成5成底仓。若小级别背驰买入后仍跌，依次等待更大级别的背驰。

五、什么时候做、什么时候必须停手

✓ 全力做T的行情

  • 箱体震荡——最友好的环境，价差稳定，复利最快。
  • 主升中继洗盘——大趋势向上、日内震荡，双向盈利。
  • 大盘震荡整理——无系统性风险、板块轮动平稳。
  • 日内振幅 ≥ 3% 才有足够差价空间。

✕ 坚决停手的行情

  • 单边主升浪——容易卖飞，尽量少做甚至不做T。
  • 单边下跌趋势——反弹空间小，越T套越深。
  • 高位破位暴跌——趋势彻底反转，只守不动或减仓避险。
  • 日内振幅 < 1.5%——差价不够覆盖摩擦成本，直接休息。
时机规律（他承认"不绝对，但多数交易日符合"） 上午 10:00–11:00 常为全天低点区域 → 适合正T；下午 13:30–14:30 常为全天高点区域 → 适合反T。此外，每天先看美股隔夜表现判断A股开盘基调。

六、心法与思维观念（他认为这才是最难的部分）

"做T最难的不是技术，而是心法。" 他花大量篇幅讲的是观念转变：

  • 算总账，不算单笔：T飞了不是坏事——说明上升趋势来了，剩余底仓即将赚钱。"某种角度讲，反倒是热切地期待T飞。"买卖追求的是总体盈亏，而不一定是每一单的盈亏。
  • 不分别、不执着：不要分别"正T好、反T不好"，不要执着于"根深蒂固的上升趋势"。实事求是、因地制宜，下降趋势来了就做反T，即使月线级暴跌也不会仓位失控。
  • 概率思维：站在50%概率的中道，不偏执不执着。K线有骗线，但"某些位置我们的概率会占优"——这就是高胜率模式的意义。
  • 把大亏回避掉：炒股结果只有小亏、小赚、大亏、大赚四种。回避大亏，留下另外三种，你就是赢家。"炒股暴富是运气，长久复利才是本事。"
  • 等待忍耐："连分钟级别都没耐心等的人，那应该是真的不适合炒股。"善于等待，专门等"天时地利人和"的机会，做一次胜过别人做很多次。
  • 专一专注：不要频繁换方法、换股票。"没有不好的股票，只有不好的操作。"先做好一只再说。
  • 降低预期：弱市时把差价预期设为多日平均振幅的 1/2 或 2/3。"一天做一点，不要想着一口吃成个胖子。"
  • 顺势而为（真正的含义）："96均线下行，做空为主，不忘做多；96均线上行，做多为主，不忘做空。任何级别都可以。"
  • 生活观：股市上班就做T，股市下班/放假就学会"闲"。"见了便做，做了就放下。"不要让盘面影响心性。

七、可执行清单（把上面全部压成一页）

1
盘前：选票与设参
选月线底部、基本面稳、平均振幅>3%的票，凑够8只分散行业。软件设好：均线 96/24/6，RSI 6，全周期统一。
2
盘前：定计划
标出次日支撑位与压力位，提前算好"预测交易法"的下影线买点、上影线卖点，提前挂单。看隔夜美股定基调。
3
开盘：判三重方向
判个股96均线（5分钟/15分钟）方向 → 判大盘、板块方向 → 看是否共振。共振看涨做正T，共振看跌做反T，不一致就观望。
4
盘中：等信号
96均线上行 + RSI(6)到20附近 + 底分型止跌缩量 → 正T买入；96均线下行 + RSI(6)到80附近 + 顶分型无量反弹 → 反T卖出。1份1份做，当天闭环。
5
高胜率窗口：重拳出击
大盘+板块+个股同频共振时，可多份出击。每周抓到一两次，成本下降就非常明显。
6
收盘：核对仓位
底仓股数与开盘一致（不增不减），差价落袋。做错了认错，绝不把T单变成隔夜补仓。

八、客观评述（供参考）

这套体系的合理之处
  • 过滤噪声、化繁为简：只用一根均线 + 一个RSI就完成了"方向 + 买卖点"的闭环，可执行性强，避免了多指标互相打架。
  • 仓位纪律是真正的护城河："5成底仓 + 5成机动 + 分批有序 + 当日闭环"这套规则，客观上限制了下行风险，比"满仓赌方向"稳健得多。
  • 顺势、不预测：与主流量化/趋势交易思想一致，长期具有正期望的基础。
需要警惕的地方
  • "成本做到负数"在数学上需谨慎理解：严格说，频繁买卖的差价是累计已实现收益，摊薄的是"心理成本/摊余成本"，并不代表持股本身没有风险敞口。
  • 交易成本是隐形杀手：高频做T对手续费、印花税、滑点极其敏感。佣金未降到万1.5以下时，差价很容易被摩擦成本吃光。
